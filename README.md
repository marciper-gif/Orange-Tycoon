# Laranja Império 3D — Citrus Tycoon SP

## Como publicar na Vercel

### Opção 1: Via CLI (mais rápido)
1. Extraia este ZIP em uma pasta no seu computador.
2. Abra o terminal na pasta e execute:
   ```bash
   npx vercel --prod
   ```
3. Siga o login (se necessário) e pressione Enter para confirmar as opções padrão.

### Opção 2: Via GitHub + Vercel
1. Crie um repositório no GitHub e envie os arquivos `index.html` e `vercel.json`.
2. Acesse https://vercel.com/new, selecione o repositório e clique em **Deploy**.
